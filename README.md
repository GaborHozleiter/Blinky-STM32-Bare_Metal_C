A basic STM32 projectrunning on the Nucleo-G070RB board.

Currently, it toggles an LED connected to PA5 and uses a button on PC13 for input.

Planned Features:

- Replace button polling with EXTI interrupt handling

- Add a watchdog timer that triggers if the button is not pressen within 10 seconds


This project is a starting point and will be gradually extended as part of my STM32 learning path.
